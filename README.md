
# PlanetPulse - Carbon Footprint Tracker

**Hackathon ID:** [AZIS-Y7U8TT]

A real-world climate tech web application designed to track and convert daily transportation, energy, and dietary choices into visible carbon footprint metrics.

## Tech Stack
- Framework: Next.js / React
- Styling: Tailwind CSS
- Charts: Recharts
- Icons: Lucide React

## Features
- **Activity Logging:** Supports travel (car, bus, flight), electricity, and diet (veg/non-veg meals) with standard fixed emission multipliers.
- **Visual Analytics:** Breakdown charts and cumulative metric cards.
- **Weekly Carbon Budget:** Target tracking with dynamic progress alerts.
- **Data Filtering:** Filter past logs by activity category and date ranges.
- **Absurd Value Guard:** Proactive sanity checks for outlier inputs.
